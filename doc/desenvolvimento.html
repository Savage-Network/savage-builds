Desenvolvimento

Build com Gradle (build.gradle.kts). Código em src/main/java.

Requisitos

  • JDK 17+ (ou superior) para executar o Gradle 9.x.
  • O plugin compila para bytecode Java 8 (compatível com Spigot 1.8).
  • Internet na primeira vez — download do Gradle (wrapper) e dependências Maven.

IntelliJ IDEA

  1. File → Open na pasta do repositório (deteta build.gradle.kts).
  2. Aguardar sync Gradle.
  3. Painel Gradle → savagebuilds → Tasks → build → build.

Linha de comandos

gradlew.bat clean build

Linux/macOS: ./gradlew clean build

O script build.bat na raiz do projeto executa o Gradle e copia o JAR para a raiz como savagebuilds.jar.

Artefacto

Ficheiro final: build/libs/savagebuilds.jar — contém o plugin, FastBoard e MySQL Connector. Spigot API e WorldEdit são compileOnly (fornecidos pelo servidor).

Estrutura útil

  • plugin.yml, config.yml — empacotados no JAR
  • craftscripts/ — scripts WorldEdit usados pelo /bs
  • database.sql — esquema MySQL opcional
