SavageMC Builds

Plugin de construção para Spigot / Bukkit 1.8: extensão do WorldEdit com comandos extras, cargos, tags no chat, scoreboard, MySQL opcional e configuração unificada.

SavageMC LTDA — servidor competitivo e arcade em Java. Produção: henqks, desenhar, zrafa.

O que inclui

  • Construção — /bs e //: gradiente, xadrez, listras, outline, colorswap, paleta, measure, walls, floor, replace, clear, undo/redo.
  • Staff — randomfill, terraform, heightmap, formas 3D, schematics.
  • Social — cargos, tags, rankings /top e /topblocos, comandos de brincadeira.
  • Dados — MySQL opcional (tags, cargos, tempo de jogo, blocos colocados).

Começar

  1. Leia Instalação (WorldEdit obrigatório).
  2. Consulte Comandos e Permissões.
  3. Para compilar o JAR, veja Desenvolvimento.
