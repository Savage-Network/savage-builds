Instalação

Requisitos e passos para colocar o servidor de builds a funcionar.

Requisitos

  • Servidor Spigot / Bukkit 1.8 (bytecode Java 8 no plugin).
  • WorldEdit na pasta plugins/ — o plugin estende WorldEditPlugin e partilha a configuração.
  • Ficheiro savagebuilds.jar gerado pelo build (Gradle).
Sem o WorldEdit correto, o plugin não carrega. Use uma build compatível com 1.8.8 (WorldEdit 6.x para Bukkit).
O plugin precisa de WorldEdit (nome interno WorldEdit) ou FastAsyncWorldEdit (FastAsyncWorldEdit) em plugins/. Sem isso, o Builds desativa ao iniciar com mensagem no log. O build já não depende de depend: [WorldEdit] no Bukkit — só tens de ter o JAR do WE/FAWE instalado.

Passos

  1. Coloque primeiro o WorldEdit.jar em plugins/ (obrigatório).
  2. Copie savagebuilds.jar para plugins/.
  3. Reinicie o servidor.
  4. A pasta de dados do plugin segue o nome em plugin.yml (ex.: plugins/Builds/) com config.yml, tags e cargos.

MySQL (opcional)

Se ativar a base de dados em config.yml, execute o script database.sql no seu MySQL antes ou deixe o plugin criar a estrutura conforme a implementação. A tabela builds guarda tags, cargos, tempo de jogo e blocos colocados.

Acesso ao servidor

Por defeito, apenas jogadores com cargo ou permissão de bypass podem entrar. Em config.yml, open-to-all: true abre o servidor a todos (útil para testes).
