Comandos

Comando principal: /bs e atalho //. Ajuda geral: /sb (aliases: /savagebuilds, /savageb).

Geral

Comando Descrição
/sb Lista comandos, cargo e prefixo.
/top [n] Ranking por tempo de jogo (com tag).
/topblocos [n] Ranking por blocos colocados.

Builder — construção

Seleção com bastão (WorldEdit). Exemplos: /bs gradient 35:0 35:15 v, // outline stone.

Comando Notas
/bs gradient Gradiente entre dois blocos; v|h|d para eixo.
/bs checkerboard Padrão xadrez.
/bs stripes Listras; eixo opcional x, y, z.
/bs outline Arestas da seleção.
/bs colorswap Troca cores em blocos coloridos (0–15).
/bs palette Paleta wool, clay ou glass.
/bs measure, clear, undo, redo Medir, limpar, histórico.
/bs walls, floor, replace Paredes, chão, substituição.

Staff — avançado

Área Comandos
Terrain /bs randomfill, terraform, heightmap
Formas circle, sphere, cylinder, pyramid, ellipsoid
Schematics /bs save, load, list

Brincadeira

Permissão savagebuilds.fun (incluída no cargo Builder na configuração padrão).

  • /slap <jogador>, /rocket [jogador], /hat
  • /hug, /kiss, /confetti, /flip

Cargos e tags

  • /cargos, /cargos list, /cargos info <nick>, /cargos set (conforme cargo)
  • /tag — menu; /tag <nome> — membro, builder, staff, admin, chefia, pp; /tag lista (staff)
  • /setcargo <nick> <cargo> — admin/staff conforme permissões

Admin

  • /sbreload — recarregar config.yml
  • /sudo <jogador> <comando> — executar como o jogador
