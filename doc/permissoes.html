Permissões

Hierarquia típica: admin > staff > build. Definições completas em plugin.yml.

Cargos principais

Permissão Função
savagebuilds.build Builder — ferramentas de construção, WorldEdit, Multiverse (tp/spawn próprio), etc.
savagebuilds.staff Staff — inclui build + ferramentas avançadas, teleporte a outros, schematics, etc.
savagebuilds.admin Admin — acesso ampliado (comandos de servidor, sudo, tags de outros, etc.).
savagebuilds.bypass Entrar sem cargo (quando o servidor exige cargo).

Outras permissões

  • savagebuilds.cargos — ver próprio cargo (/cargos)
  • savagebuilds.setcargo — definir cargos (staff limitado; admin completo)
  • savagebuilds.fun — comandos de brincadeira
  • savagebuilds.sudo — /sudo
  • savagebuilds.tag.* — tags por nome (builder, staff, admin, chefia, master/pp, …)

Tags

Cada tag tem permissão própria (ex.: savagebuilds.tag.chefia). No jogo, use /tag para escolher entre as tags permitidas ao seu cargo.

LuckPerms / grupos

Atribua os nós savagebuilds.* aos grupos correspondentes no teu plugin de permissões. Após alterar nomes de permissões, sincroniza os grupos com o plugin.yml atual.
